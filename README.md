> **Стек:** Python 3.11 · pyTelegramBotAPI · SQLite · Docker SDK · APScheduler

| Функция | Описание |
|---|---|
| 🔐 Авторизация | Регистрация (имя + пароль) и вход по паролю |

## 🚀 Быстрый запуск

### 1. Получите токен бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

### 2. Подготовьте `.env`

```bash
cp .env.example .env
# Откройте .env и вставьте токен в BOT_TOKEN=...
```

### 3. Запустите через Docker Compose

```bash
# Сборка и запуск
docker compose up -d --build

# Просмотр логов
docker compose logs -f

# Остановка
docker compose down
```

## 🔑 Администрирование

ID администратора: `5429363551` (задан в `bot.py` → `ADMIN_ID`).

**Доступные действия:**
- 💰 **Выдать кредиты** — начислить кредиты пользователю (с уведомлением)
- 🖥 **Выдать сервер** — создать бонусный сервер пользователю
- 🚫 **Забанить** — заблокировать аккаунт (сессия сбрасывается)
- ✅ **Разбанить** — восстановить доступ
- 🔧 **Тех. работа** — включить/выключить режим обслуживания

---

## 🔄 Кредитная система

- Каждый новый пользователь получает **25 кредитов**
- Каждый час за каждый **работающий** сервер списывается **1 кредит**
- При балансе ≤ 5 кредитов пользователь получает предупреждение
- При 0 кредитов все серверы останавливаются автоматически
